## The problem

Three platforms implemented the same design system by hand. Colours drifted,
spacing scales diverged, and dark mode shipped on web four months before it
shipped anywhere else. Every design review turned into an audit.

## Approach

Tokens live in one JSON source of truth. A build step compiles them into
whatever each platform actually consumes: CSS custom properties for web, a
Swift enum for iOS, an XML resource file for Android.

The important part was making the generated files unwritable by hand — the
build fails if a generated file has local edits, so drift cannot re-enter
through a well-meaning patch.

## Outcome

Dark mode shipped across all three platforms in the same release. Visual QA
time on design reviews dropped by roughly two thirds, since reviewers stopped
checking whether platforms matched and started checking whether the design was
right.

## What I would change

I would generate the token documentation from the same source. Writing it
separately meant the docs were wrong within a month.
