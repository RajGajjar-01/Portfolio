A Kanban board application built on Django: create multiple boards, organize
tasks across columns, and manage it all behind Google-style authentication via
Django Allauth.

- Multiple boards per user, each with its own set of columns and tasks.
- Django REST Framework API alongside the server-rendered views.
- Styled with TailwindCSS v4 and DaisyUI, with built-in light/dark themes.
- User profiles with avatar support, backed by Django's ORM and Pillow for image handling.

The frontend is server-rendered Django templates with Tailwind's standalone
CLI compiling styles — no Node build step required to run it.
